# Fusion_RubberWrapping

選択したボディに、指定した重力方向から１枚のラバー（膜）をかぶせた様なサーフェスを作成する Autodesk Fusion 用スクリプトです。

**生成される形状には不完全な部分があります。** 使用前に「注意事項」を確認してください。

---

## インストール

インストールする際は、zip ファイルをダウンロード／展開後、「RubberWrapping」フォルダをスクリプトとして登録してください。

スクリプトの登録は、[こちら](https://kantoku.hatenablog.com/entry/2021/02/15/161734)の手順に従ってください。

---

## 使用法

1. Fusion でデザインを開き、「スクリプトとアドイン」から `RubberWrapping` を実行します。
2. ダイアログで対象ボディを１つ以上選択します。ソリッド、サーフェス、メッシュボディに対応します。
3. 必要に応じて重力方向を構築軸、スケッチ線、または直線エッジで指定します。未指定の場合は **-Z 方向** です。「方向反転」で向きを逆にできます。ダイアログ表示中は矢印で方向を確認できます。
4. 必要に応じて「詳細設定」を開き、計算パラメータを変更します。
5. **OK** を押すと進捗ダイアログが表示され、処理後に所要時間が表示されます。

### 詳細設定

| 項目 | 初期値 | 内容 |
| --- | ---: | --- |
| 分割数 | 30 | 平面の X・Y 方向それぞれの分割数 |
| 余白 | 0.5 cm | ボディの範囲から片側に広げる距離 |
| 厚み | 0.05 cm | ボディ表面からの計算上の浮き量 |
| 膜の反復回数 | 2000 | 膜の形状を求める反復回数 |
| SOR 係数 | 1.8 | 反復計算の緩和係数 |
| 平滑化の反復回数 | 20 | 表面を平滑化する反復回数 |
| 補正回数 | 3 | スムース面の高さを補正する回数 |

余白と厚みは、ダイアログではデザインの長さ単位で表示されます。表の初期値は cm 換算です。分割数を増やすと細部を拾いやすくなりますが、処理時間も増えます。

---

## 仕組み

選択したボディの重力方向から見える上面を、膜が下回らないための障害物として扱います。ボディの範囲に余白を加えた格子上で高さを計算し、T スプライン平面の頂点を移動します。ソリッド・サーフェスボディにはレイとの交点を使い、メッシュボディには三角形の投影を使います。細い突起についてはメッシュ節点の高さでも補正します。

---

## 注意事項

- **出来上がりの形状には不完全な部分があります。** 格子と近似計算による形状のため、細い突起、急な段差、細かな凹凸を正確に再現できない場合があります。生成後の形状を確認し、必要に応じて手作業で修正してください。
- 重力方向から見えない裏側やオーバーハングの下には回り込みません。生成されるのは１枚の開いた面で、ボディ全体を密閉する形状ではありません。
- 「厚み」は表面からの浮き量です。生成される Form に物理的な肉厚を付ける設定ではありません。
- 実行時、デザインの種類がパラメトリック（履歴あり）に切り替わります。
